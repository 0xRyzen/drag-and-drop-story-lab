# Story Lab 0.1.0

## Added to the supplied Scene Builder foundation

- Complete episode planning from one simple description rather than supplied
  clip-by-clip production prompts.
- Four to eight 15-second clips, story-fit runtime persisted once.
- Structured beat coverage, timed shot and dialogue contracts.
- Exact cast, valid connected anatomy, and body/console separation.
- Native ambience, timed sound effects, quiet original score and dialogue mixing.
- Explicit local Skill source and hash provenance.
- Read-only ChatGPT-authenticated Codex directing and visual QA.
- Immutable public GitHub source intake; bounded credit and retry guards.
- Reusable 14-node n8n orchestration and atomic private run checkpoints.

## Deliberate limits

- First pilot enables Episode 1, Jack/Karega and existing room assets only.
- Later episode drafts do not automatically launch on the initial repository push.
- No automatic creation of new character/prop designs.
- No separate paid TTS/music service and no OpenAI API fallback.
- Audio-content QA is not implemented; sampled visual QA is not every-frame QA.
- No new multi-episode queue, old-workflow migration or automatic runtime redeploy.

The original user-supplied SKILL.md is retained byte-for-byte in `provenance/`.
The Story Lab edition is an enhanced derivative, not an identical installed copy.
