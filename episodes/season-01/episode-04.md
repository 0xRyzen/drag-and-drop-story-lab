# Episode 4 - The Empty Copy

Using the pause, Jack makes one copy of the suspicious file on the existing console. Karega discovers that the copy contains no useful content, while the original appears to respond to their attention. They debate whether the file is evidence or bait. Jack moves the empty copy into the original position, and the machine follows the decoy. End with the genuine file briefly left unguarded on the same screen.
